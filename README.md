# keylogger
## Introduction

  This repository contains a basic keylogger script that records and logs all keyboard input to a text file named "keylog.txt". It uses the pynput library to listen to keyboard events and write the input to the log file.
## Features

  Records all keyboard input, including characters, numbers, and special keys
  Logs input to a text file named "keylog.txt"
  Can be stopped by pressing the Esc key

## Requirements

  Python 3.x
  pynput library (install with pip install pynput)

## Usage

  Clone this repository with 
    
    git clone https://github.com/DinooBose/keylogger.git
    
  Navigate to the repository directory with cd keylogger
    
  Run the script with Python 
    
    python3 keylogger.py
    
  The script will start logging keyboard input to "keylog.txt"
  Press the Esc key to stop the script
